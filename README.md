# Zapowiedzi MPK Kraków

Baza zapowiedzi przystankowych i liniowych komunikacji miejskiej w Krakowie: odsłuchiwanie i pobieranie zapowiedzi każdej linii, archiwum dawnych nazw oraz filmik z trasy.

Strona: https://gabik0wski04.github.io/gabik0wski04/

Mapa w filmiku: Esri World Imagery, © OpenStreetMap / OpenFreeMap. Biblioteka mapy: MapLibre GL JS (licencja w `lib/maplibre-LICENSE.txt`).
